01 / The idea

A new perspective on robot programs

From words
to aerial action.

A coding agent can write a robot’s task program. But when the outcome is unclear, what should it do next?

Fly-by-Code lets the agent write another program—this time to investigate. It moves to a better viewpoint or tests a physical hypothesis in simulation, then uses the evidence to judge completion and improve the next attempt.

A separate diagnostic stage

Diagnosis starts from the state left by the task attempt. The task score is recorded before diagnosis, and the scene resets before the next task-program execution. Evidence informs both completion assessment and program revision.
